视频复刻工作台 · 便携版
==============================

一、启动
--------
1. 解压整个文件夹，双击 VideoRecreate.exe。
2. 等待原生窗口出现。关闭窗口即退出程序。
3. 不要把文件夹放在 C:\Program Files 等只读位置；建议放桌面或文档目录。

二、系统要求
------------
- Windows 10 / 11 64 位。
- 原生窗口依赖 Microsoft Edge WebView2 Runtime 和 .NET Framework 4.6.2+。
  下载：https://developer.microsoft.com/microsoft-edge/webview2/
- 如果没有 WebView2，程序会回退到 Edge 的独立应用窗口（不是浏览器标签页）；请确保 Edge 已安装。
- 首次使用口播转写时，需要联网下载 Whisper 模型（默认 small）；之后会缓存在 data/models。

三、数据与设置
--------------
- 所有任务保存在 data/outputs。
- 运行日志在 data/logs。
- 点左下角「设置」填写 API 密钥和接口地址，然后「测试连接 / 拉取模型」并「保存配置」。
- API 密钥只保存在本机 data/config.json，不会写入程序文件。
- 整个文件夹可以移动或改名；建议保持「任务输出目录」为相对值 outputs。

四、工作流程
------------
1. 新建任务。
2. 01 获取素材：粘贴链接下载，或上传本地视频。默认按原画下载。
3. 02 拆解复刻：
   - 填全片统一设定和额外要求，可上传人物 / 产品 / 风格参考图。
   - 抽帧、可选口播转写，然后拆解生成分镜。
   - 在分镜表「参考附件」列填 @别名；脚本汇总和生视频都会使用。
   - 生成关键帧、生成视频。
4. 03 合成去重：选镜头、可选 BGM / 字幕 / 去重、选输出分辨率，生成成片。
5. 右侧菜单切换「素材 / 分镜·关键帧 / 成片 / 日志」。

五、常见问题
------------
- 双击没反应：查看 data/logs/launcher.log 和 data/logs/streamlit.log。
- 窗口空白 / 启动超时：查看 data/logs/streamlit.log；确认没有杀毒软件拦截。
- 提示 data 目录不可写：把整个文件夹移到桌面或文档目录。
- 下载失败：抖音 / 快手需要 Git Bash 脚本和网络；其它平台走 yt-dlp。日志里会显示具体错误。
- 口播转写失败：首次需要联网下载模型；检查 data/logs。
- 被杀毒软件 / SmartScreen 拦截：这是 PyInstaller 打包程序的常见误报。请将 zip 解压前「解除锁定」，并把整个文件夹加入信任；正式分发建议做代码签名。
- 分享给别人前：请删除 data/outputs 里的个人素材，并确认 data/config.json 中没有你的 API 密钥。

六、开源与许可
--------------
程序包含第三方组件：Streamlit、Python、pandas、PyArrow、NumPy、faster-whisper、
CTranslate2、tokenizers、PyAV、ONNX Runtime、PyInstaller、pywebview、pythonnet、
FFmpeg、yt-dlp、Git for Windows 以及若干 Skill 脚本。
详细许可见 THIRD_PARTY_NOTICES.txt 和 LICENSES 目录。
